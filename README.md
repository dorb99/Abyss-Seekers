# Abyss-Seekers

A final project developed during the Cyberpro bootcamp, Abyss-Seekers is a game created using C# and Unity. Over an intensive 7-day period, our team of four delved into new technologies to bring this project to life.

## Project Overview

In a team of four, we embarked on a 7-day final project. We collectively decided to prioritize self-learning, a skill we deemed the most important from our bootcamp experience. With this decision made, we set out on a challenging task: learning C# and Unity in just one week to develop a game.

The journey was intense, with long hours into the night. In fact, we found ourselves unexpectedly spending two consecutive nights in the office just before the presentation. Despite the challenges, we persevered and learned a lot along the way, not only about C# and Unity but also about effective teamwork and collaboration.

My role primarily focused on the backend aspects of the project. I handled SQL data storage, backend functions, and class development. Additionally, I pitched in to assist my teammates in various other areas as needed.

Overall, it was a demanding yet rewarding experience that pushed us to our limits and expanded our skill sets.

## Features

- **Gameplay Mechanics:** Engaging and challenging gameplay designed to test players' skills.
- **Backend Integration:** Utilizes SQL for data storage, ensuring a robust and scalable backend.
- **Collaborative Development:** Built through effective teamwork and collaboration, highlighting the importance of self-learning and adaptability.

## Technologies Used

- **C#** – Core programming language for game development.
- **Unity** – Game engine used for designing and building the game.
- **SQL** – Database management for storing game data.

## Installation and Setup

To run Abyss-Seekers locally, follow these steps:

### 1. Clone the Repository
```bash
git clone https://github.com/dorb99/Abyss-Seekers.git
cd Abyss-Seekers
```

### 2. Install Dependencies
Ensure you have Unity and the necessary modules installed. Open the project in Unity to install required packages.

### 3. Build and Run
Within the Unity editor:
- Open the project.
- Navigate to the **Build Settings**.
- Select your target platform.
- Click on **Build and Run**.
